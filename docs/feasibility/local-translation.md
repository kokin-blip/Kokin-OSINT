# Local translation feasibility — defer

The present broker exposes cited suggestion tasks and no analytical tools. Its
native fixture path preserves original observations and human review; the actual
BGE retrieval gate passes eight English paraphrase queries. Neither result measures
translation fidelity. Ollama and generative weights are absent on the reference Mac.

Decision: **defer**. Preserve original text and located citations; a translation
would be a versioned derivative with language, engine, resource identity and clear
limitations. Do not overwrite evidence or treat translated wording as an exact
original-byte quote.

Estimated implementation cost: one separate reviewed increment for language
selection, bounded jobs, derivative citations and UI; representative bilingual
human evaluation is additional work. Adoption requires a pinned/license-reviewed
model, measured named-entity/negation/date preservation on a reviewed parallel
corpus, missing-language and cancellation tests, explicit human review, and package
restore proof. No translation destination ships in this delivery.
